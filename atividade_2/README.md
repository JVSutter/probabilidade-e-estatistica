## Atividade 2

#### Dependências
Para executar os _scripts_, primeiro instale as dependências necessárias: `pip install -r requirements.txt`.

#### Scripts
Na pasta `/src`, encontram-se os scripts necessários para testar as hipóteses. Os resultados desses scripts foram utilizados na elaboração do relatório. Caso deseje executar algum, faça-o a partir do diretório atividade_2: `python /src/<nome_do_script>`

#### Outputs
Na pasta `/outputs`, foram armazenados os resultados dos scripts, isto é, a amostra aleatória e os gráficos.
